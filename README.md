# Сайт Morui

Готовый сайт на Jekyll (GitHub умеет собирать такие сайты сам, без установки чего-либо на твоём компьютере). Разделы: «О себе», «Команда», «Проекты», «Блог».

## Как опубликовать (один раз)

1. На GitHub создай **новый** репозиторий с именем **`morui.github.io`** — важно, чтобы имя совпадало с твоим username в точности, иначе GitHub Pages не заработает автоматически.
2. Загрузи в него все файлы из этой папки, сохранив структуру (папки `_layouts`, `_includes`, `_posts`, `assets` — как есть).
3. Зайди в репозитории в **Settings → Pages**.
4. В поле **Source** выбери **Deploy from a branch**, ветка — `main`, папка — `/ (root)`. Сохрани.
5. Через 1–2 минуты сайт будет доступен по адресу **https://morui.github.io**.

## Как добавить новую запись в блог (без кода)

1. Открой на GitHub папку `_posts`.
2. Нажми «Add file → Create new file».
3. Имя файла строго по образцу: `2026-09-20-nazvanie-zapisi.md` (дата — год-месяц-день, дальше — короткое название латиницей через дефис).
4. В начало файла вставь:
   ```
   ---
   title: "Заголовок записи"
   ---
   ```
5. Дальше пиши обычный текст — он появится на странице автоматически, ничего больше трогать не нужно.
6. Commit changes — через минуту запись появится на `/blog/`.

## Как добавить нового участника команды

Открой `team.md`, скопируй одну строку вида
```
<li><span>Имя</span><span class="role">роль</span></li>
```
и вставь новую с нужным именем и ролью — прямо внутри списка `<ul class="roster">`.

## Как добавить новый проект

Открой `projects.md`, скопируй один блок `<div class="project"> ... </div>` целиком, вставь ниже и поменяй текст внутри. Значение в `<span class="status">` — статус проекта, есть три готовых стиля: без класса (активный), `status paused` (на паузе), `status done` (завершён).

## Свой домен позже

Если решишь купить домен (например `morui.me`) — просто добавь файл `CNAME` с одной строкой (именем домена) в корень репозитория и пропиши DNS-записи у регистратора на GitHub Pages. Всё остальное на сайте менять не придётся.
