# Morui visual redesign — v1

The site was restyled around the supplied black / rust-red / grainy print references.

## Main changes
- Dark, rust-red editorial aesthetic.
- Oversized poster-like header typography.
- Layered grain, scanline and print-style overlays without external image assets.
- New mono technical typography for navigation/status labels.
- Team roster converted into poster/archive-style blocks.
- Project entries converted into framed editorial cards with hover motion.
- Blog list converted into archive-style rows.
- Subtle mouse-parallax effect on the header background and grain layer.
- Mobile breakpoints and reduced-motion support included.

## Files changed
- `_layouts/default.html`
- `assets/css/style.css`
- `assets/js/site.js`

No page text was changed.
